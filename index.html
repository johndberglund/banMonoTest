The question

A 2-isohedral tiling has two classes of tiles: the symmetries of the tiling move every tile onto every other tile of its own class, but never onto a tile of the other class. Usually the two classes have different shapes. The question for each type is whether some choice of shapes makes the two classes congruent, so that a single tile shape fills the whole plane in that pattern (a monohedral tiling).

For many types the answer is no. A typical proof finds a set of points that one tile class is forced to contain, and a region the other class can never leave. If no rotation, reflection or translation fits those points inside that region, the two tiles cannot have the same shape, for any choice of shapes at all.
