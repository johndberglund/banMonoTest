## Tegula

The drawing engine -- turning a Delaney-Dress symbol into a fundamental domain, its relaxation, and the
incidence structures (the `dsym_*.js` files and `draw_dsym2.js`) -- follows the method and data structures of
**Tegula** by Daniel Huson and Rüdiger Zeller, based on code by Klaus Westphal
(<https://github.com/husonlab/tegula>), which is licensed under the GNU GPL version 3. Its source was studied
while writing this engine, so this code is released under the same license.
